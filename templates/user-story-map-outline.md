# User Story Mapping Outline Template

User story mapping helps organize stories by user journey and prioritize releases.

---

## Backbone (User Activities - high level)

1. Discover / Browse
2. Evaluate / Decide
3. Purchase / Convert
4. Receive / Onboard
5. Use / Engage
6. Get Support / Renew

---

## Walking Skeleton / MVP Slice

Select the minimum set of stories under each activity that delivers an end-to-end valuable experience.

| Activity | MVP Stories | Later Releases |
|----------|-------------|----------------|
| Discover | | |
| Evaluate | | |
| Purchase | | |
| ... | | |

---

## Detailed Mapping Structure

```
User Activity
|-- User Task
    |-- User Story (with priority & size)
        |-- Acceptance Criteria
```

Example:

```
Purchase
|-- Complete checkout
    |-- US-001 Guest checkout (Must, 8)
    |-- US-002 Progressive steps (Must, 13)
    |-- US-003 Show shipping early (Must, 5)
```

---

## Facilitation Tips
- Start with the backbone (activities) before writing stories.
- Horizontal = user journey; Vertical = priority / necessity.
- Use the map in backlog refinement and release planning conversations.
