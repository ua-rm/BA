# Project Glossary
## E-Commerce Modernization

| Term | Definition | Notes |
|------|------------|-------|
| **Guest Checkout** | Ability to complete a purchase without creating or logging into an account | Core MVP requirement |
| **Progressive Checkout** | Checkout experience that advances the user through steps with minimal full-page reloads and retained data | |
| **Cart Abandonment Rate** | Percentage of initiated checkouts that do not result in a completed purchase | Primary success metric |
| **MVP** | Minimum Viable Product - the smallest set of features that delivers the core value and allows learning | Phase 1 scope |
| **MoSCoW** | Prioritization technique: Must, Should, Could, Wont | Used for backlog |
| **WCAG 2.1 AA** | Web Content Accessibility Guidelines level AA | Non-functional requirement |
| **OMS** | Order Management System | Existing system of record for orders |
| **CSAT** | Customer Satisfaction Score | Post-purchase survey metric |
| **RTM** | Requirements Traceability Matrix | Links objectives -> requirements -> tests |
