## About This Portfolio

This repository showcases practical Business Analyst deliverables across the full project lifecycle. Each project includes realistic artifacts that hiring managers and clients expect to see:

- Clear problem statements and business objectives
- Well-structured requirements (functional & non-functional)
- User stories with acceptance criteria
- Process models and gap analysis
- Data analysis and insights
- Stakeholder communication artifacts

## Core Competencies

| Domain | Skills Demonstrated |
|--------|---------------------|
| **Requirements** | Elicitation, prioritization (MoSCoW), documentation, traceability |
| **Process Modeling** | swimlane diagrams, value stream mapping, gap analysis |
| **Agile Delivery** | User stories, acceptance criteria, backlog refinement, sprint support |
| **Data Analysis** | SQL, Excel analysis, KPI definition, dashboard requirements |
| **Stakeholder Mgmt** | RACI, communication plans, workshop facilitation notes |
| **Documentation** | BRD, FRD, use cases, process documentation, decision logs |

## Tools & Techniques

- **Modeling**: UML (Use Case, Activity), mermeid diagrams
- **Data**: SQL, Excel
- **Collaboration**: Jira / Cloud DevOps style backlogs, Confluence-style docs
- **Frameworks**: Agile (Scrum/Kanban), Lean, MoSCoW, RACI
