# Requirements Traceability Matrix (RTM)
## Sample - E-Commerce Modernization (Excerpt)

Traceability ensures every business objective is supported by requirements and can be verified.

| Business Objective | Req ID | Requirement Summary | User Story / Spec | Priority | Test / Verification Approach | Status |
|--------------------|--------|---------------------|-------------------|----------|------------------------------|--------|
| Reduce cart abandonment to < 50% | BR-01 | Enable guest checkout | US-001 | Must | UAT + Analytics funnel comparison | In Progress |
| Reduce cart abandonment to < 50% | BR-02 | Progressive checkout with minimal steps | US-002 | Must | Usability test + session time metrics | In Progress |
| Reduce cart abandonment to < 50% | BR-03 | Show shipping options & cost early | US-003 | Must | UAT + cart abandonment analysis | Refined |
| Improve mobile conversion >= 25% | BR-04 | Mobile-optimized checkout experience | US-006 | Must | Device lab testing + mobile conversion rate | Refined |
| Improve product discovery | BR-05 | Recently viewed products | US-004 | Should | Analytics - click-through on module | Draft |
| Improve product discovery | BR-06 | Personalized / related recommendations | US-005 | Should | A/B test plan + engagement metrics | Draft |
| Maintain CSAT >= 4.2 | BR-07 | Clear order confirmation & expectations | (linked to notification stories) | Must | Post-purchase CSAT survey | Not Started |

---

### Notes
- Keep the RTM lightweight; link to detailed specs rather than duplicating content.
- Update status during refinement and after testing.
- Useful for impact analysis when scope changes are requested.
