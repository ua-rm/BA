---

## RACI Legend
- **R** - Responsible (does the work)
- **A** - Accountable (owns the outcome, final decision)
- **C** - Consulted (provides input before decision/action)
- **I** - Informed (kept up to date)

---

## Matrix

| Activity / Decision | Executive Sponsor | Product Owner | Engineering Lead | UX / Design | BA | Operations | Marketing |
|---------------------|-------------------|---------------|------------------|-------------|-----------------|-----------|-----------|
| Define business objectives | A | C | I | I | R | I | I |
| Approve scope / MVP | A | A | C | C | R | C | C |
| Prioritize backlog | I | A | C | C | R | I | C |
| Approve designs | I | C | C | A | C | I | C |
| Technical approach | I | C | A | C | C | I | I |
| Go-Live decision | A | C | C | C | R | C | I |
| Post-launch review | A | R | C | C | R | C | C |

---

## Usage Tips
- Only one **A** per row (clear ownership).
- Keep the number of **C**s manageable to avoid decision paralysis.
- Review and socialize the RACI early; update when roles change.
- Pair with a communication plan for the **I** stakeholders.
